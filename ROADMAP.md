# Roadmap

Initial work focuses on reliable repository selection, isolated worktrees,
same-terminal Pi replacement, durable history, and conservative cleanup.

Future candidates, not part of the initial release:

- Read-only agent tools for history and repository discovery
- Explicit user-approved mutating agent tools
- Additional Git-host support
- Windows support
- Optional custom base-branch selection
- Native optimization only when profiling demonstrates a real bottleneck
